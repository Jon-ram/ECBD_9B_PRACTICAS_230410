# Práctica 11 — Algoritmos de Análisis No Supervisado: Clientes de Centros Comerciales

## Descripción
Este notebook aplica el algoritmo K-Means para segmentar clientes de un centro comercial usando el dataset `Mall_Customers.csv`, replicando y documentando en español el notebook original de Kaggle "Unsupervised Learning: 3-6 Clusters | K-Means | EDA".

## Contenido de la carpeta
- `unsupervised-learning-3-6-clusters-k-means-eda.ipynb` — Notebook con el desarrollo completo de la práctica.
- `Mall_Customers.csv` — Dataset utilizado.
- `README.md` — Este archivo.

## Requisitos
- Python 3.x
- Jupyter Notebook o JupyterLab
- Librerías: pandas, numpy, matplotlib, seaborn, scikit-learn

Instalación rápida de dependencias:
```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

## Instrucciones de ejecución
1. Clonar o descargar esta carpeta del repositorio.
2. Asegurarse de que el archivo `Mall_Customers.csv` esté en la misma carpeta que el notebook.
3. Abrir el notebook con Jupyter Notebook o JupyterLab.
4. Ejecutar todas las celdas en orden con la opción **Restart & Run All** para garantizar que corra de principio a fin sin errores.
5. Revisar las gráficas y conclusiones generadas al final del notebook.
