# Extracción del Conocimiento de Base de Datos

Repositorio correspondiente a la práctica de la materia **Extracción del Conocimiento de Base de Datos (ECBD)**.

## Descripción

Este proyecto realiza el análisis y procesamiento del conjunto de datos **School Donations** utilizando Python y Jupyter Notebook.

Debido al gran tamaño de los archivos de datos (varios gigabytes), estos **no se incluyen en el repositorio** y se encuentran ignorados mediante el archivo `.gitignore`.

---

## Instalación

1. Clonar el repositorio.

2. Descargar el dataset desde alguno de los enlaces anteriores.

3. Extraer los archivos (si es necesario).

4. Copiar los archivos CSV dentro de la carpeta donde se encuentra el notebook.
